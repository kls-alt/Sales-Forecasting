# Sales-Forecasting
Пайплайн генерации синтетических данных, feature engineering и обучения модели регрессии.

## Стек технологий
* Language: Python
* Libraries: Scikit-learn, Pandas, NumPy, Matplotlib

## Что было сделано (Пайплайн проекта)
* Генерация данных: Создан синтетический датасет, симулирующий ежедневные продажи.
* Feature Engineering: Разработаны признаки на основе временных рядов (лаги, скользящее среднее `rolling_mean_7d`, флаги выходных дней).
* Валидация: Реализован хронологический сплит (train/test) во избежание утечки данных (data leakage).
* Моделирование: Обучена базовая модель `RandomForestRegressor`.
* Оценка качества: Качество модели оценено с помощью метрики MAE (Mean Absolute Error).
* Интерпретация: Проведен анализ важности признаков (Feature Importance) и построена визуализация.
* Прогнозирование: Реализован финальный расчет предсказаний на будущий период.

## Результаты
* Построен рабочий пайплайн прогнозирования «из коробки».
* Выявлены наиболее значимые признаки для модели.
